# As regras do chat

O moderador tira do chat **só** o que quebra uma das regras abaixo. Edite à vontade: cada linha numerada é uma
regra, lida quando o app sobe. Tudo o que não está aqui fica — gíria, palavrão solto, zoeira leve, reclamar do jogo.

1. Xingamento ou humilhação dirigidos a uma pessoa (ao streamer ou a quem está no chat).
2. Discurso de ódio: racismo, homofobia, misoginia, xenofobia, capacitismo.
3. Assédio sexual ou conteúdo sexual explícito.
4. Ameaça, ou incentivo a alguém se machucar.
5. Spam: propaganda, link suspeito, a mesma coisa repetida para encher o chat.
6. Dado pessoal de alguém (telefone, endereço, CPF).
7. Pedir dinheiro, Pix ou doação para si mesmo (mandar presente para o streamer não é isso).
